CalWATRS Measurement Package

From logger readings to a Board-ready A1 file

A Qualified Individual prepares measurement packages for claimed water rights. This prototype shows the job in miniature: start from a measurement device on a mid-size agricultural diversion, adjust a few sample measurements, and download a Demo A1 CSV for Diversion to Direct Use.

CalWATRS is the State Water Resources Control Board portal. The Board still receives the filing from a person. This page only drafts a demonstration Template Data File. It is not the full product: no Device registry, no Methodology draft, no Filing checklist, and no Audit log.

What-if demo

Defaults come from a sample logger: pulses in the hour ending at each time, times 10 gallons. Flow rate is that volume divided by the minutes since the previous row. The first row is the start mark. Change any measurement and the Demo A1 CSV follows. Reset restores the sample.
